About SysMon

Project Overview

Title: SysMon - Cross-Platform System Monitor


SysMon is a real-time system monitoring cross-platform web app built as a CS50x 2026 Final Project. The backend is powered by Python and Flask, which constantly pulls live hardware data and serves it to the frontend via a RESTful API. The application is designed to work seamlessly right out of the box on both Windows and Linux environments.

Tech Stack & Dependencies

  • Python: Core Backend (v3.14.5)
  • Flask: API Routing Framework
  • 🐍 psutil: Native Hardware Monitoring Engine
  • 🛠️ WMI / Py-cpuinfo: Low-Level Hardware Diagnostics
  • ⚡ GPUtil: Graphics Processing Unit Monitor
  • JavaScript: Frontend Polling Controller
  • 📈 Chart.js: Frontend Data Visualization
  • HTML5: Core Document Structure
  • CSS3: Styling Architecture
  • Bootstrap 5: Layout Framework
Data acquisition occurs via non-blocking asynchronous intervals every 1.0 seconds to eliminate interface thread locks.
